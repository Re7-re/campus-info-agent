# campus-info-agent
    本项目是基于LangGraph构建的校园信息智能查询智能体，面向学生、教师与管理员提供一站式校园服务。
    系统通过第三方大模型 API 实现自然语言意图识别，自动调用封装的查询工具，支持成绩、课表、选课、空教室、考试安排、校园通知、校园卡、校历等高频查询功能，采用文本交互为主、语音交互为辅的设计。
    后端使用 FastAPI 封装模拟数据接口，前端基于 Gradio 快速搭建可视化交互界面，实现 LLM 意图理解、智能路由调度、工具自动调用、结果自然语言生成的完整 Agent 工作流。
    项目模块化易扩展，适合深度学习工程实践与智能体开发学习。
